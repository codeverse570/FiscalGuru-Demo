# 💰 FiscalGuru
### AI-Powered Financial Advisor Matching Platform

FiscalGuru is a platform that connects financial advisors with clients using AI-based intelligent matching. The system helps users find the most suitable financial advisor based on their financial goals, preferences, and requirements.

---

## 🚀 Features

- 🤖 AI-based Advisor–Client Matching
- 📱 Flutter Mobile Application
- 🔐 Secure Document Storage (Encrypted Hive Storage)
- 👥 Role-Based Authentication (Advisor / Client)
- 📄 Financial Document Upload & Management
- 🔔 Notifications & Updates
- 🌐 REST API Backend
- 🐳 Dockerized Backend Services
- 🏗️ Scalable System Architecture

---

## 🛠️ Tech Stack

**Frontend**
- Flutter

**Backend**
- Node.js
- Express.js

**Database**
- MongoDB

**AI Integration**
- Gemini APIs (Advisor Matching / Recommendation)

**Security**
- Hive Encrypted Storage
- Authentication & Authorization

**DevOps**
- Docker

---

## 🏗️ System Architecture

The system is designed using modular architecture with multiple services:

- User Service
- Advisor Matching Service
- Document Service
- Notification Service
- Authentication Service

This architecture makes the system scalable and easy to maintain.
